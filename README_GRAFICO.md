# Atualização do gráfico de carga operacional

O gráfico de barras foi substituído por cartões de progresso clicáveis. Cada cartão apresenta o total de pontos, número de condomínios, percentual da referência provisória de 145 pontos e classificação de cor. Ao clicar, abre a carteira do síndico.

Faixas: até 70% verde; acima de 70% até 90% amarelo; acima de 90% até 100% laranja; acima de 100% vermelho. Referência e limites são provisórios, não indicadores de produtividade.

## Publicação
Substitua apenas `public/index.html` no repositório GitHub, faça commit e aguarde a Vercel atualizar. O pacote também inclui os demais arquivos do projeto para referência.

## Segurança
O painel legado é demonstrativo e não tem autenticação de produção. Não use CPFs ou senhas reais até a migração completa do backend.
